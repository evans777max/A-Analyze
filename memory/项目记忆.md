## §2 常设约定

1. **收盘日更**：每交易日收盘后核对快照落地、结算观察日志中的待验证项（O 系列）、更新记忆
2. **周度复盘**：每周五收盘后出当周复盘，MD（GitHub 直读）+ HTML（Pages）双格式，流金简版另出一页纸 PDF；README「周度复盘记录」表登记
3. **模型改动纪律**：页面 / snapshot / audit 三处同口径，validate-repo 锚点校验守护；模型口径变更需升 Model Version 并在 model-meta 纪元表登记
4. **观察→固化流程**：盘面现象先入观察日志（O 系列，含可证伪的验证条件）→ 收盘 / 多样本验证 → 固化为规则（R 系列）并进模型；反方向同样成立（审计判负即退役，如 rsPen）
5. **推演纪律**：已验证的审计规律优先级高于叙事推理（2026-08-10 教训固化）；盘中结论一律以收盘为准（R3，双向适用）
