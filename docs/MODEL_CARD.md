# A-Analyze · Model Card

> Model Version: **4.0** · History Schema Version: **2** · 更新：2026-08

## 用途

对一个人工维护的 A 股主题池（当前集中于 AI/算力链 + 北交所标的）做**当下状态强度**的规则化打分与风险警示，辅助人工看盘与复盘研究。

## 不适用用途

- **不是收益预测**：全年样本内审计（约 3700 观测）显示总分与次日收益无稳定相关。
- 不是投资建议、不是自动交易信号源、不适用于池外标的或其他市场。
- 页面展示的"参考档位"仅为单一标的计划资金内的参考区间表述。

## 模型结构（四层加权 + 风险规则）

| 层 | 权重 | 内容 |
|---|---|---|
| L1 市场环境 | 20% | 所属基准指数、上证/深成/创业板、基准-参照价差 |
| L2 全球情绪 | 15% → 8%* | 隔夜美股、恒生科技（盘中）、日经/KOSPI |
| L3 板块联动 | 25% | 相关性加权联动篮子涨跌 + 联动票上涨占比 |
| L4 个股动能 | 40% | 均线结构、20日位置、相对强弱（日内+5日）、量能 |

\* v4.0 时变权重：交易日 10:00 前 15%，之后 8%。依据：跨市场审计显示隔夜美股与 A 股开盘跳空相关约 0.5（全年稳定），与开盘后日内走势相关约 0——隔夜信息在跳空中一次性兑现。

**风险规则**（触发时在判定文字透明展示）：

- 过热惩罚（扣分，封顶 20）：2日/5日累计涨幅超涨跌幅上限倍数阈值。样本内审计：被罚样本次日均值约 -2.7%、3 日约 -7.8%（同期全池约 +0.4%）——**样本内显著，等待样本外实录继续验证**。
- 状态透支警示（不扣分）：评分高出自身 60 日常态 +1σ。样本内：此类样本次日均值约 -0.4%。
- 退潮高分警示（不扣分）：主线状态=退潮且评分≥55。样本内：下跌主线中高分组次日 IC 约 -0.12。
- 背离警示（v2.7 曾扣分，v4.0 退役为提示）：日内大幅跑输基准。退役依据：样本内审计显示该扣分方向打反。
- 硬规则：跌破趋势防线强制防守档；基准单日大跌禁止进攻档；无利空盘中破位 + 环境层健康时提示假摔可能（以收盘为准）。

## 数据来源

公开行情接口：腾讯（实时报价/分时）、新浪（日K主源）、东方财富（日K备源、日韩指数）。无付费数据、无内幕信息、无第三方依赖包。

## history.json Schema（v2）

每标的一个数组，每元素为一个交易日记录：

| 字段 | 含义 | 出现时段 |
|---|---|---|
| `d / s / p / pct` | 日期 / 收盘评分 / 收盘价 / 涨跌幅 | 全部记录 |
| `bf: 1` | 回填重算标记（v3.x 口径，非实录） | 约 2026-08-05 及以前 |
| `h / l / to` | 当日最高 / 最低 / 换手率 | v4.0 起（2026-08-10 起） |
| `l1..l4 / op` | 分层评分 / 过热扣分 | v4.0 起 |
| `mv / sv` | 模型版本 / schema 版本标记 | v4.1 管线上线起 |

模型纪元（epoch）边界见 `data/model-meta.json`。**v3.x 与 v4.0 评分不完全可比**（rsPen 与 L2 权重口径变化），跨纪元对比轨迹时注意。

## 已知偏差（解读任何统计结果前必读）

1. **幸存者/选择偏差**：股票池为 2026-08 人工选定的当时热门主题票，用它回看历史会高估这些票的特性。
2. **corr90 前视**：主标的关联池的 90 日相关性基线为 2026-08 筛选口径，用于更早历史存在前视。
3. **主题集中**：池子高度集中于 AI/算力，结论不外推到全市场。
4. **重叠样本**：fwd3/fwd5 收益窗口相互重叠，独立样本量小于名义观测数，显著性被高估。
5. **无交易成本**：所有分组收益/息差均为理论值，不可直接解读为可交易 Alpha。
6. **样本内 vs 样本外**：截至目前全部审计结论均为**样本内**（用同一段历史提出并检验假设）。2026-08-10 起的 v4.0 实录快照构成首批样本外数据，计划按月复检。
7. **L4 量能因子在平盘处不连续**：量比得分按涨跌方向取反（`pct >= 0 ? lin(vr) : 100 - lin(vr)`），在 `pct = 0` 处硬跳变，且缩量时跳变最大。2026-08-11 实测流金科技 vr=0.70：收平走"涨"分支得 5.3 分，若收跌 1 分则走"跌"分支得 94.7 分——层内跳变 89.5 分，经 L4 内 20/120 与总分 40% 放大为总分 6.2 分，并跨一个档位（观望 49.9 ↔ 积极持有 56.1）。因子意图（放量涨好、放量跌坏）本身合理，但**恰好收平的缩量样本会被顶格判负**，并会产生"收跌反而评分更高"的读数。解读平盘/微幅波动样本时须知此偏差。修正（平盘区间内平滑过渡）会改变模型行为并打断 v4.0 实录可比性，列入 `docs/ROADMAP.md` 待样本外复检后决策，v4.0 内不改。
