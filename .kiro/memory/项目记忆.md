## §3 模型规格（v3.1）

- 四层：L1市场环境20%（基准指数随标的市场适配+价差）/ L2全球情绪15%（隔夜美股+恒生科技+日韩）/ L3板块联动25% / L4个股动能40%（MA结构/RS/20日位置/量比折算/vsMA20）
- L3：主标的=精筛关联池（2026-08 基线：数码视讯0.64/华数传媒0.49/优刻得0.48/中国卫通0.34/云赛智联0.33，corr90 硬编码）；其他票=30日实际联动自动匹配（全池+6指数锚点，ρ≥0.30，样本≥20日，取前5）
- 归一化：联动篮子 pct 按涨跌幅限制折算到 10cm 口径（北交30/双创20/主板10）；RS 和软规则刻意不折算（用户确认过的行为）
- 硬规则：破趋势防线强制防守档；基准大跌>1.5%禁进攻档
- 软规则1（用户确认）：日内跑输基准>1.5pct，超出部分×10 扣分，封顶15，归因表透明展示
- 软规则2 过热惩罚（v3.2，用户确认，起因=汉鑫两日+60%得97分暴露动能模型盲区）：2日累计涨幅>1.5×涨跌幅上限 或 5日>2×上限，超出部分递进扣分（2日超出/上限×30、5日超出/上限×20，取大者封顶20），评分旁标"过热"标签，归因表透明展示
- 仓位档：≥70进攻60-80% / 55-70持有40-60% / 40-55观望20-40% / <40防守0-20%
- 价格带自动推导（60日高/20日前高/MA10-20/20日低+ATR去重），`CONFIG.MANUAL_LEVELS` 支持按票手工覆盖（null=全自动）
- 量比盘中按已开盘分钟折算（240分钟制），修正上午低估

## §4 功能清单

- 自选池：默认 20 只 AI/云/IDC/芯片题材票（含众诚/拓维/汉鑫），用户可增删（6位码自动识别市场，上限40，localStorage），列可排序（默认评分降序，偏好记忆），筛选框
- 分享：`?list=代码,...` 快照分享 + `?stock=代码` 深度链接（可组合）；分享互不影响本机自选
- 多票切换：点自选表股票名整页切换；主标的流金可一键返回
- 评分历史：每日留痕 localStorage（aa_hist_v1），评分卡下方近20日轨迹 SVG
- 主题：浅/深双主题（aa_theme_v1），顶栏切换，默认跟随系统；深色参考用户 Forge 风格（近黑#09090b+天蓝accent），红涨绿跌不变
- 剧本：条件式四格，当前区间高亮
